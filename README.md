## 🇬🇧 English

This project is a **console-based zoo management simulation** developed using Java and Object-Oriented Programming (OOP) principles.  

The system models different types of animals using **abstract classes and interfaces**, allowing flexible and extensible design.

Each animal has its own behaviors (such as eating, making sounds, or moving), and these behaviors are defined using interfaces to ensure consistency across different animal types.

The project focuses on practicing:

- Object-Oriented Programming (OOP)
- Abstract classes and inheritance
- Interface-based design
- Polymorphism
- Clean and maintainable class structure

---

# ✨ Features

- 🐾 Abstract `Animal` class  
- 🧬 Different animal types (e.g., Lion, Elephant, Bird)  
- 🔊 Interface-based behaviors (sound, movement, etc.)  
- 🔁 Polymorphic method usage  
- 🧱 Clean OOP architecture  
- 🧪 Easy to extend with new animals

## 🇹🇷 Türkçe

Bu proje, Java ve Nesne Yönelimli Programlama (OOP) prensipleri kullanılarak geliştirilmiş **konsol tabanlı bir hayvanat bahçesi simülasyonudur**.  

Sistem, farklı hayvan türlerini **abstract class ve interface yapıları** ile modelleyerek esnek ve genişletilebilir bir yapı sunar.

Her hayvanın kendine özgü davranışları (yemek yeme, ses çıkarma, hareket etme vb.) vardır ve bu davranışlar interface kullanılarak standart hale getirilmiştir.

Projenin amacı:

- OOP mantığını geliştirmek  
- Abstract class ve inheritance kullanımı  
- Interface ile davranış modelleme  
- Polymorphism kavramını pekiştirmek  
- Temiz ve sürdürülebilir kod yazımı
